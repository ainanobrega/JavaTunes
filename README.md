# JavaTunes
Projeto atualizado de um simulador de gerenciamento de playlist de músicas e podcasts, permitindo organizar e manipular faixas de forma simples

O projeto também conta com testes unitários utilizando o JUnit, garantindo o funcionamento esperado das principais funcionalidades do sistema. 

- FUNCIONALIDADES
    * Adicionar músicas à playlist;
    * Remover músicas;
    * Buscar músicas;
    * Listar músicas da playlist;
    * Simular reprodução das músicas;
    * Gerenciar a ordem das músicas;
    * Testar as funcionalidades utilizando JUnit
 
  - TECNOLOGIAS UTILIZADAS:
      * Java
      * JUnit

    - TESTES:
Os testes foram desenvolvidos utilizando JUnit para verificar o comportamento das principais funcionalidades do gerenciamento de playlists.
Entre os testes realizados estão:
  * Adição de músicas;
  * Remoção de músicas;
  * Busca de músicas;
  * Verificação da quantidade de músicas;
  * Validação do comportamento da playlist em diferentes situações.
